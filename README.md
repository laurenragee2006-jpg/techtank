# techtank

Started as a school project, ended up being something we actually wanted to use.

Techtank is a deal flow tool for investor groups — a single link you put on your website 
lets founders apply directly. From there, everything lands in one dashboard where you can 
review applications, leave notes on candidates, track status, and run AI queries to filter 
your pipeline without manually reading through everything.

Built this because investor groups (especially student-run ones) were managing deal flow 
through email threads and spreadsheets. This cleans that up.

## What it does

- Branded application form for founders to submit through
- Dashboard where your team can review, filter, and tag applicants
- AI search — ask in plain English, get back matching candidates
- One-click diligence report generation per applicant
- Team notes and status tracking (new, reviewed, shortlisted, passed)

## Tech

HTML, CSS, JavaScript — no frameworks. Backend via serverless API routes. Deployed on Vercel.
