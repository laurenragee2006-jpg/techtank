# techtank

The codebase behind [Lucent](https://techtank-rho.vercel.app) — a deal flow tool 
for investor groups.

Started as a school project at Tennessee Tech, ended up being something we actually 
wanted to keep building. A lot of investment groups are managing their 
whole pipeline through email threads and Google Sheets, which gets messy fast. 
Lucent gives them one place to handle everything.

Founders apply through a single branded link. Submissions land in a structured 
dashboard where your team can review, tag, and track every applicant. You can also 
just ask the AI in plain English to filter your pipeline instead of manually sorting 
through everything.

## What it does

- Application form founders submit through (one link, no back and forth)
- Dashboard to review and track applicants as a team
- Auto-tagging by sector, stage, location, and raise target
- AI search — type a question, get back matching candidates
- One-click diligence report per applicant
- Status tracking and team notes

## Tech

HTML, CSS, JavaScript. Serverless API routes on the backend. Deployed on Vercel.

## Status

Still actively building.
